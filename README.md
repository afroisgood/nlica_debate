# 辯論活動互動系統

為現場辯論活動打造的計時與觀眾互動網頁。主持人用主畫面控制流程、投影給全場看；觀眾用手機掃 QR Code 即可投票、留言，所有內容即時同步到主畫面。

純 HTML / CSS / JavaScript，不需要建置步驟或安裝套件，部署在 GitHub Pages，資料透過 Firebase Realtime Database 即時同步。

## 頁面一覽

| 頁面 | 使用者 | 用途 |
|---|---|---|
| `index.html` | 主持人／投影畫面 | 計時器、流程控制、各題即時投票結果、與談人票選、留言牆 |
| `vote.html` | 現場觀眾(手機) | 各題 A／B／C 投票、與談人票選、留言、按讚 |

## 活動流程

共 5 題，每題 15 分鐘：

1. 與談人選邊站、觀眾投票(3 分鐘)
2. 與談人立場說明(8 分鐘)
3. 觀眾發言 1(2 分鐘)
4. 觀眾發言 2(2 分鐘)

5 題結束後依序為：觀眾投票／休息(10 分鐘)→ 頒獎時間(5 分鐘)→ 與談人分享(15 分鐘)→ 活動結束。

## 功能介紹

### 主畫面(`index.html`)

**計時與流程**
- 依上面的流程逐階段進行，每個階段有各自的時間長度
- 開始／暫停、重置、上一階段／下一階段，也可以點進度格或用下拉選單跳到任一階段
- 時間可以臨時加減 30 秒或 60 秒，超時會顯示超出時間
- 顯示目前是第幾題、下一階段預告
- 支援全螢幕投影
- 鍵盤快捷鍵：空白鍵開始／暫停、← → 切換階段、R 重置、F11 全螢幕

**投票顯示**
- 題目進行中：右上方即時顯示這一題 A／B／C 的票數與比例(A 紅、B 藍、C 黃，使用短標籤)
- 觀眾投票／休息時段：顯示與談人票選的總票數，各人票數不公開
- 「公布結果」：以全螢幕畫面揭曉當題結果；題目結束後則揭曉與談人票選排名

**留言牆**
- 即時顯示觀眾留言與按讚數

**管理功能**(需要管理員登入才能操作)
- 開放／停止投票
- 清除投票(5 題＋與談人票選)、清除留言
- 刪除單則不當留言
- 匯出活動紀錄(各題結果、與談人票選、留言)為文字，方便複製保存

未登入時所有控制按鈕都會鎖定，避免投影畫面被誤觸。

### 觀眾參與頁(`vote.html`)

- 第一次進入時設定暱稱(之後可以修改)
- 題目進行中：顯示題目與 A／B／C 三個完整選項，該題 15 分鐘內可以隨時改選；投票後會看到這一題目前的投票比例
- 觀眾投票／休息時段：投給最能說服你，或最能代表你對未來花蓮期待的與談人，休息結束前可以改選
- 發表留言(最多 100 字)，並對其他人的留言按讚
- 畫面會跟著主畫面的目前階段自動切換，不需要重新整理

## 活動當天使用流程

1. 在投影電腦開啟主畫面，登入管理員
2. 按「QR Code」讓觀眾掃碼進入參與頁
3. 依流程開始計時、切換階段
4. 每題結束前可按「公布結果」揭曉該題投票
5. 頒獎時按「公布結果」揭曉與談人票選
6. 活動結束後按「匯出資料」保存紀錄

## 部署

推送到 `main` 分支後，GitHub Pages 約 1 分鐘內自動更新，無需建置。

## 自訂內容

- **題目與選項、與談人名單**：`index.html` 與 `vote.html` 各有一份，兩邊需要同步修改
- **各階段時間**：修改 `index.html` 中的階段設定
