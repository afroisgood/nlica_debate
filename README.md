# 辯論活動互動系統

為現場辯論活動打造的計時與觀眾互動網頁。主持人用主畫面控制流程、投影給全場看；觀眾用手機掃 QR Code 即可投票、留言、提問，所有內容即時同步到主畫面。

純 HTML / CSS / JavaScript，不需要建置步驟或安裝套件，部署在 GitHub Pages，資料透過 Firebase Realtime Database 即時同步。

## 頁面一覽

| 頁面 | 使用者 | 用途 |
|---|---|---|
| `index.html` | 主持人／投影畫面 | 計時器、流程控制、即時投票與留言牆、抽選觀眾提問 |
| `vote.html` | 現場觀眾(手機) | 投票、留言、按讚、匿名提問、下期題目票選 |
| `questions.html` | 工作人員 | 審核與管理觀眾提問 |

## 功能介紹

### 主畫面(`index.html`)

**計時與流程**
- 依預設賽程逐階段進行(立論、質詢、觀眾提問、回應、結辯、觀眾投票、開放討論等),每個階段有各自的時間長度
- 開始／暫停、重置、上一階段／下一階段，也可以從下拉選單或進度點直接跳到任一階段
- 時間可以臨時加減 30 秒或 60 秒
- 顯示下一階段預告
- 支援「自由辯論」雙方各自計時的模式，可一鍵切換發言方
- 支援全螢幕投影
- 鍵盤快捷鍵：空白鍵開始／暫停、← → 切換階段、R 重置、F11 全螢幕

**觀眾互動顯示**
- 顯示 QR Code，觀眾掃描即可進入參與頁
- 即時顯示正反方得票數與比例
- 即時留言牆，標示留言者支持的立場與按讚數
- 「公布結果」:以全螢幕畫面揭曉投票結果
- 「抽選提問」:在觀眾提問階段，以拉霸動畫隨機抽出一則該方的提問，並全螢幕顯示
- 下期題目票選：全版顯示各題目的即時票數，倒數結束後自動截止

**管理功能**(需要管理員登入才能操作)
- 開放／停止投票
- 清除投票、清除留言、重置題目票選
- 刪除單則不當留言
- 匯出活動紀錄(投票結果、留言、題目票選)為文字，方便複製保存
- 前往提問管理頁

未登入時所有控制按鈕都會鎖定，避免投影畫面被誤觸。

### 觀眾參與頁(`vote.html`)

- 第一次進入時設定暱稱(之後可以修改)
- 投票支持正方或反方，投票開放期間可以隨時改票
- 發表留言(最多 100 字),並對其他人的留言按讚
- 隨時可以按「提問」按鈕，選擇要問正方或反方，**匿名**送出問題
- 到了「下期題目票選」階段，畫面會自動切換成題目票選
- 畫面會跟著主畫面的目前階段自動切換，不需要重新整理

### 提問管理頁(`questions.html`)

- 需要登入才能使用
- 分正方／反方列出所有觀眾提問，即時更新數量
- 可以刪除單則提問，或一次清空全部提問
- 被刪除的提問不會出現在主畫面的抽選名單中

## 活動當天使用流程

1. 在投影電腦開啟主畫面，登入管理員
2. 按「QR Code」讓觀眾掃碼進入參與頁
3. 依流程開始計時、切換階段
4. 觀眾提問階段使用「抽選提問」
5. 投票階段結束後按「公布結果」
6. 活動結束後按「匯出資料」保存紀錄

## 部署

推送到 `main` 分支後，GitHub Pages 約 1 分鐘內自動更新，無需建置。

## 自訂內容

- **賽程階段與時間**:修改 `index.html` 中的階段清單
- **下期題目選項**:`index.html` 與 `vote.html` 各有一份題目清單，兩邊需要同步修改
